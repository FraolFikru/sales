# Bistro Ledger

Sales & expense tracker for Bistro Addis: purchases with smart item search,
sales by payment method (Cash, Card, Mobile banking), payables and reconciliation.

## Run
Open `index.html` in any modern browser. No install or build step needed.

## Notes
- Single self-contained file (HTML + CSS + JavaScript).
- Sample data is generated relative to today's date.
- Records you add are kept in memory and reset when the page reloads;
  only the light/dark theme choice is saved in the browser.
